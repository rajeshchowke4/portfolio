Getting Started

Clone Repository

Clone the project from GitHub.

git clone https://github.com/rajeshchowke4/portfolio

Install Dependencies

Navigate into the project and install the required packages.

npm install

Environment Variables

Create a .env file using .env.example and configure your database and JWT secret.

cp .env.example .env

Run Development Server

Start the application using the development command.

npm run dev
